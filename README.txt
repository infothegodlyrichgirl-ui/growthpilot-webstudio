GrowthPilot Web Studio - static website

1. Preview: open index.html in your browser.
2. Publish: upload this whole folder to Netlify, Cloudflare Pages or GitHub Pages.
3. Before going live, search all files for YOUR-DOMAIN.com and replace it with your real domain (also in sitemap.xml and robots.txt).
4. Contact form: put your Formspree address in app.js (formEndpoint).
5. Edit text directly in the .html files; colours and layout are in style.css.
